### Changed

- `doctor` without `--profile` now checks the profile the repository declares: `new` writes a `<!-- project-canon profile: <name> -->` marker as the first line of the generated `CONFORMANCE.md`, and repositories generated by earlier versions are recognised from their template sentence. Without a declaration the default stays `cli`, an explicit `--profile` still wins, and `--json` reports the choice as `profile_source` (`flag`, `conformance-md`, or `default`).

### Fixed

- Generated `AGENTS.md` and `CONFORMANCE.md` for the `service`, `library`, and `release` profiles name `project-canon doctor --profile <name>` instead of a bare `project-canon doctor` that checked the CLI profile.
